Privacy Policy

Effective date: November 4, 2026

This policy describes how the application "Everyday Intelligence" (the "App") handles data. The App is a private publishing tool operated by the owner of the YouTube channel Everyday Intelligence. It runs on the owner's own computer and is used only to upload the channel's own videos to the channel's own YouTube account.

Data the App accesses

The App uses Google OAuth and the YouTube Data API to access the channel owner's YouTube account. It uses this access only to upload videos, set their titles, descriptions, tags, scheduled publish times and thumbnails, and to read basic channel information needed to do so.

How data is used and stored

OAuth tokens are stored locally on the owner's computer inside the workflow software (n8n) and are used only for the purposes above. The App does not collect, sell, share or transfer any personal data to third parties, does not use data for advertising, and does not access data of any other YouTube or Google user.

YouTube API Services

The App uses YouTube API Services. By using the App you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Revoking access

Access can be revoked at any time on the Google security settings page. After revocation the App can no longer access the account; locally stored tokens become invalid.
